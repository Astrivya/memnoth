# MSI Packaging for memnoth

This directory contains the WiX Toolset configuration for building an MSI installer.

## Prerequisites

- WiX Toolset v4+ (https://wixtoolset.org/)
- .NET SDK 8.0+
- Built `memnoth.exe` binary (from `cargo build --release --target x86_64-pc-windows-msvc`)

## Building the MSI

```powershell
# From CLI directory
cargo build --release --target x86_64-pc-windows-msvc -p memnoth
# Binary at: target/x86_64-pc-windows-msvc/release/memnoth.exe

# Build MSI
cd packaging/msi
dotnet build memnoth.wixproj -c Release
# Output: bin/Release/memnoth-<version>-x64.msi
```

## WiX Project Structure

```
packaging/msi/
├── memnoth.wixproj          # MSBuild project
├── Product.wxs              # Main product definition
├── Fragments/
│   ├── Files.wxs            # File components
│   ├── Shortcuts.wxs        # Start Menu shortcuts
│   ├── Registry.wxs         # Registry entries
│   └── Path.wxs             # PATH environment variable
├── Assets/
│   ├── memnoth.exe          # Copied from cargo build output
│   ├── LICENSE.txt
│   └── icon.ico
└── README.md                # This file
```

## Product.wxs Template

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Wix xmlns="http://wixtoolset.org/schemas/v4/wxs">
  <Package
    Name="memnoth"
    Version="$(var.Version)"
    Manufacturer="Astrivya"
    UpgradeCode="PUT-GUID-HERE"
    InstallerVersion="500"
    InstallScope="perMachine"
    Platform="x64"
    Description="Terminal agent, bi-temporal vault, code graph and MCP server"
    Comments="memnoth - local-first AI development environment"
    Keywords="cli,terminal,ai,mcp,code-graph,vault,developer-tools"
  >
    <MajorUpgrade DowngradeErrorMessage="A newer version of memnoth is already installed." />
    <MediaTemplate EmbedCab="yes" />
    <Feature Id="Main" Title="memnoth" Level="1">
      <ComponentGroupRef Id="memnothComponents" />
    </Feature>
    
    <!-- Add to system PATH (requires admin) -->
    <Environment Id="AddToPath" Name="PATH" Value="[INSTALLDIR]" Action="set" Part="last" Permanent="yes" System="yes" />
    
    <!-- Start Menu shortcuts -->
    <DirectoryRef Id="ProgramMenuFolder">
      <Component Id="StartMenuShortcuts" Guid="PUT-GUID-HERE">
        <Shortcut
          Id="memnothShortcut"
          Name="memnoth"
          Description="Terminal agent, bi-temporal vault, code graph and MCP server"
          Target="[INSTALLDIR]memnoth.exe"
          WorkingDirectory="INSTALLDIR" />
        <Shortcut
          Id="mnShortcut"
          Name="mn (memnoth alias)"
          Description="memnoth alias"
          Target="[INSTALLDIR]memnoth.exe"
          Arguments="mn"
          WorkingDirectory="INSTALLDIR" />
        <RemoveFolder Id="ProgramMenuFolder" On="uninstall" />
        <RegistryValue Root="HKCU" Key="Software\Astrivya\memnoth" Name="Installed" Type="integer" Value="1" KeyPath="yes" />
      </Component>
    </DirectoryRef>
  </Package>
  
  <Fragment>
    <Directory Id="TARGETDIR" Name="SourceDir">
      <Directory Id="ProgramFiles64Folder">
        <Directory Id="INSTALLDIR" Name="memnoth" />
      </Directory>
      <Directory Id="ProgramMenuFolder">
        <Directory Id="ApplicationProgramsFolder" Name="memnoth" />
      </Directory>
    </Directory>
  </Fragment>
  
  <Fragment>
    <ComponentGroup Id="memnothComponents">
      <Component Id="memnothExe" Guid="PUT-GUID-HERE" Directory="INSTALLDIR">
        <File Id="memnothExe" Source="Assets/memnoth.exe" KeyPath="yes" />
      </Component>
      <Component Id="LicenseFile" Guid="PUT-GUID-HERE" Directory="INSTALLDIR">
        <File Id="LicenseFile" Source="Assets/LICENSE.txt" />
      </Component>
      <ComponentRef Id="StartMenuShortcuts" />
    </ComponentGroup>
  </Fragment>
</Wix>
```

## Version Handling

The version is passed via MSBuild property:
```powershell
dotnet build memnoth.wixproj -c Release -p:Version=0.1.0-beta.1
```

Or read from a `version.props` file generated by the release workflow.

## GUID Generation

Generate GUIDs for:
- UpgradeCode (stable across versions): `dotnet wixguid` or PowerShell `[Guid]::NewGuid()`
- Component Guids (one per component): `*`

## Integration with Release Workflow

The MSI should be built in the release workflow after the Windows binary is built, and uploaded as a release asset alongside the zip file.

See `.github/workflows/cli-release.yml` for the build matrix that produces `memnoth-x86_64-pc-windows-msvc.zip`.
